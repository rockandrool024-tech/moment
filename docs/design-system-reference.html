00 What each reference actually gave us

Not a literal copy of any one — the shared instinct across all three, applied in MOMENT's own palette and copy.

Fitness / social app

Big confident numbers, one per screen. Segmented pill tabs. A one-word verdict next to a stat ("Solid," "Good"). → §3.6 Stat card, §2.2 Segmented control.

Safety / evacuation app

Tap a pin, a sheet slides up with chips and one clear primary action. → the Sheet component, already shipped and used on /map and the funding flow.

Zenly-style 3D map

Dark "home base" map, avatar bubbles as pins, lowercase bold label. → /map, deliberately the only dark screen in the app.
