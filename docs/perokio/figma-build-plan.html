Two existing files in this folder are from an earlier, superseded direction. component-library.html and tokens.css document a "sunset gradient" palette (yellow→orange→red) that was proposed and then replaced. The app that's actually live today runs the black / crimson / hot-pink / pale-pink palette below (verified directly against the current globals.css) — tokens.css's own header comment confirms this. Reuse that file's structural patterns (card anatomy, button states, the segmented control, the outcome-ticket mechanic) freely — just recolor everything against the tokens in §01, not the sunset values baked into its inline CSS.
