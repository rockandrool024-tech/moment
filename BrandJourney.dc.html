Brand Journey

From "I want to see work" to "I picked the winner"

1

Create a challenge

Write brief (title, description), set prize pool, pick submission rounds (teaser → full → public vote). Escrow the cash.

✓ Current: Form on /challenges/new exists

→ Issue: Not discoverable from challenges list for brands

2

Fund the prize

Confirm prize amount. Stripe Elements form. KYB verification (one-time).

✓ Current: Funding flow exists

→ Issue: KYB gate blocks many. No clear timeline for approval.

3

Invite creators (optional)

Browse creator tiers by win count, taste score. Send direct invites. Track invites sent + accept rate.

→ Current: Invite page built but not surfaced

→ Fix: Add "Invite creators" button on challenge detail

4

Watch entries come in

See submission count grow over time. Watch submission video teaser (if round 1 is teaser phase).

→ Current: No analytics until challenge resolves

→ Opportunity: Real-time entry count widget on challenge detail

5

Manage voting rounds

Open rounds on schedule. Round 1 (blind peer voting, teaser). Round 2 (full content, blind peer voting). Round 3 (public voting, creators revealed).

→ Current: Server auto-advances rounds. Brand sees no control.

→ Opportunity: Show "Round 1 results. Advance to Round 2?" button

6

See voting data

Funnel: 126 submitted → 28 advanced to R2 → 8 finalists → 1 winner. Vote distribution per round. Creator quality metrics (taste score trending up).

→ Current: /analytics page (spec'd but not styled)

→ Fix: Use StatCard for funnel counts. Add vote distribution chart.

7

Rate winners + build track record

Rate creators 1-5 stars. These ratings build your "brand trust score" (how fair were your briefs?). Future creators see your trust level.

✓ Current: RatingForm component built

→ Issue: Not prominent enough. Brands don't see the benefit.

💡 KEY INSIGHT: Brand motivation is CONTROL → Confidence. Every screen should show: "How many entries?" + "Is it a quality pool?" + "How do I move this forward?"
